# ✊ Pierre, Papier, Ciseaux (Pygame)

Un jeu de **Pierre, Papier, Ciseaux** moderne et interactif développé en **Python** avec **Pygame**.

---

## 📸 Fonctionnalités

- 🖱️ **Interface cliquable :** Sélectionne ton arme directement à la souris avec des boutons stylés.
- 🤖 **IA réactive :** L'ordinateur choisit aléatoirement à chaque tour.
- 🏆 **Mode Match en 3 points :** Le premier joueur ou l'ordinateur à atteindre 3 victoires remporte la partie.
- 🔄 **Rejouabilité instantanée :** Relance une partie en un clic ou avec la touche `ESPACE`.

---

## 🚀 Lancement

```bash
pip install pygame
python main.py
